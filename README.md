# 🍰 Family Bakery Website

## 📌 About the Project

This project is a **website design replication** of a bakery website. The main goal of this project is to practice and improve my **HTML and CSS skills** by recreating the structure and visual design of an existing website. This project was created for **educational and practice purposes**.

## 🎯 Project Objective

The objective of this project is to:

- Practice creating a website using HTML5.
- Apply CSS styling and layouts.
- Recreate an existing website design.
- Practice working with images and icons.
- Improve my understanding of website structure.
- Practice organizing website files and folders.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Font Awesome**

## 🎨 Website Design

The website design includes:

* Navigation bar
* Hero section
* Bakery introduction
* About section
* Bakery features
* Contact and location section
* Footer
* Background images
* Icons
* Styled buttons

The design was recreated using HTML and CSS while trying to stay as close as possible to the original design.
